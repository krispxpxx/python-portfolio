# Анализ данных студентов

## Описание
Исследование и визуализация датасета с оценками студентов. Проект показывает навыки работы с данными.

## Технологии
- Python 3.10
- pandas
- matplotlib
- seaborn

## Как запустить
1. Установи зависимости: `pip install -r requirements.txt`
2. Запусти скрипт: `python analysis.py`
3. Графики сохранятся в папку `charts/`

## Результаты
- Распределение оценок по предметам
- Корреляция между предметами
- Статистические метрики

## Пример графиков
- Гистограмма оценок
- Тепловая карта корреляции
- Boxplot по предметам
