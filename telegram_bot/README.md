# Telegram-бот "Погода"

## Описание
Бот, который по команде /weather присылает текущую погоду в Москве. Простой и удобный.

## Технологии
- Python 3.10
- pyTelegramBotAPI
- requests
- BeautifulSoup

## Как запустить
1. Установи зависимости: `pip install -r requirements.txt`
2. Получи токен у @BotFather в Telegram
3. Вставь токен в переменную TOKEN в файле `bot.py`
4. Запусти бота: `python bot.py`

## Команды
- `/start` — приветствие
- `/weather` — погода в Москве
