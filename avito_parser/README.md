# Парсер Avito (учебный проект)

## ⚠️ ВНИМАНИЕ!
Этот проект создан исключительно в **учебных целях** для демонстрации навыков парсинга. Использование парсеров на Avito может нарушать их правила пользовательского соглашения. Для реальных проектов используйте официальное API или прокси-серверы.

## Описание
Скрипт собирает объявления с Avito по заданному запросу (например, "iPhone").

## Технологии
- Python 3.10
- requests
- BeautifulSoup
- pandas

## Как запустить
1. Установи зависимости: `pip install -r requirements.txt`
2. Запусти скрипт: `python main.py`
3. Результат сохранится в файл `avito_items.csv`

## Пример результата
| Название | Цена |
|----------|------|
| iPhone 13 | 50 000 ₽ |
