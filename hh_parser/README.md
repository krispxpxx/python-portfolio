# Парсер вакансий hh.ru

## Описание
Скрипт собирает вакансии с hh.ru через официальное API.

## Технологии
- Python 3.10
- requests
- pandas

## Как запустить
1. Установи зависимости: `pip install -r requirements.txt`
2. Запусти: `python main.py`
3. Результат сохранится в `hh_vacancies.xlsx`
