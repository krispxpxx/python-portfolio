# Парсер вакансий hh.ru

## Описание
Скрипт собирает вакансии с hh.ru через официальное API. Работает быстро и стабильно.

## Технологии
- Python 3.10
- requests
- pandas
- openpyxl (для сохранения в Excel)

## Как запустить
1. Установи зависимости: `pip install -r requirements.txt`
2. Запусти скрипт: `python main.py`
3. Результат сохранится в файл `hh_vacancies.xlsx`
