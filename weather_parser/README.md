# Парсер погоды

## Описание
Скрипт собирает текущую температуру и описание погоды с сайта Yandex.Погода.

## Технологии
- Python 3.10
- requests
- BeautifulSoup
- pandas

## Как запустить
1. Установи зависимости: `pip install requests beautifulsoup4 pandas`
2. Запусти скрипт: `python main.py`
3. Результат сохранится в файл `weather.csv`

## Пример результата
| city   | temperature | description |
|--------|-------------|-------------|
| moscow | -5          | Облачно     |
